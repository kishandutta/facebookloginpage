# Facebook Login Page Clone

A clean, responsive replica of the Facebook login interface created using **HTML5** and **Tailwind CSS**. This project was developed as a practical exercise to master Tailwind CSS utility classes, layout structuring, and responsive UI design principles with the guidance of online tutorials.

---

## 📌 Features

- **Pixel-Inspired Layout**: Faithfully mirrors the desktop Facebook login and sign-up landing page.
- **Utility-First Styling**: Styled entirely with Tailwind CSS utility classes for maintainable design.
- **Form Component Design**: Styled input fields with focus indicators, clean placeholder text, and intuitive action buttons.
- **Interactive States**: Smooth hover and cursor states across navigation links, buttons, and call-to-actions.
- **Modern Build Tooling**: Configured with Vite and PostCSS for instant hot module reloading and build automation.

---

## 🛠️ Tech Stack

- **HTML5**: Semantic document structure
- **Tailwind CSS (v3)**: Modern utility-first CSS framework
- **PostCSS & Autoprefixer**: CSS processing and automated vendor prefixing
- **Vite**: Ultra-fast local development server and bundler

## 🚀 Getting Started

Follow the instructions below to set up and run the project locally.

### Prerequisites

- [Node.js](https://nodejs.org/) (version 16 or newer recommended)
- [npm](https://www.npmjs.com/) (bundled with Node.js)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/kishandutta/facebookloginpage.git
   cd facebookloginpage
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

### Development Server

Start the local development server:
```bash
npm start
```

After running the command, open your browser and navigate to the local address displayed in the terminal (typically `http://localhost:5173`).
